# Plugin AnimeAV1 para Kino

Plugin para ver anime desde [AnimeAV1](https://animeav1.com) en la app Kino.

## Instalación en Kino

1. Abre la app **Kino**
2. Ve a **Plugins** (o el icono de puzzle)
3. Toca **Agregar plugin**
4. Escribe: `srhc9bp2j4-create/kino-plugin-animeav1`
5. Instala y listo 🎉

## Contenido disponible

- Episodios recientes actualizados a diario
- Catálogo completo de animes
- Búsqueda por título
- Sub Español / HD
